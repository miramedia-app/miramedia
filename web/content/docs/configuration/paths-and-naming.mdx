The `[misc]` section holds general settings: where media lives, how downloads
flow, how often background jobs run, and how files and folders are named.

## URL and CORS

- `frontend_url` — the URL you actually open MiraMedia at. **Required.** No
  trailing slash. It does not affect where the server binds and does not set a
  path prefix (see [URL Prefix](../advanced-features/url-prefix)).
- `cors_urls` — list of origins allowed to call the API. No trailing slashes.
  Only matters when the UI is served from a different origin than the API
  (e.g. local development).
- `development` — development mode toggle. Default `false`.

## Media directories

| Key                       | Default                     | Purpose                                                                                    |
| ------------------------- | --------------------------- | ------------------------------------------------------------------------------------------ |
| `image_directory`         | `/app/images`               | Poster/backdrop cache                                                                      |
| `show_directory`          | `/data/shows`               | Root TV library                                                                            |
| `movie_directory`         | `/data/movies`              | Root movie library                                                                         |
| `torrent_directory`       | `/data/torrents`            | Where finished downloads are searched/imported from                                        |
| `incomplete_torrent_path` | `/data/torrents/incomplete` | Native client downloads here, then moves to the completed path on finish. Empty = no split |
| `completed_torrent_path`  | `""`                        | Where finished downloads land. Empty = same as `torrent_directory`                         |

<Callout type="warn">

Keep `torrent_directory` (downloads) and the show/movie directories on the
**same filesystem**. MiraMedia hard-links on import; cross-filesystem
imports fall back to copying and may fail on disk space.

</Callout>

## Cleanup and continuous download

- `cleanup_after_import` — remove a torrent from the client (with its data)
  after every file in it has imported. Default `true`.
- `continuous_download` — global default for automatically downloading missing
  episodes/movies. Default `true`. Each show/movie can override this
  individually (`null` = follow the global default).
- `auto_download_interval_hours` — how often the continuous-download job runs.
  Default `1`.

## Integrity check (optional)

- `integrity_check_enabled` — store a SHA1 for each imported file and re-hash
  periodically to detect bit-rot/corruption. Default `false`.
- `integrity_check_interval_hours` — audit interval. Default `168` (weekly).

## Imports

- `auto_pick_confidence_threshold` — on **Imports**, when the top
  candidate's match confidence is above this, it's highlighted as the primary
  pick. Default `0.8`.

## Log retention

- `log_retention_days` — database log rows older than this are pruned daily.
  Default `30`. See [Logging](logging).

## Naming templates (`[misc.naming]`)

Folder and file names are rendered from Python `str.format` templates. An
invalid or empty template falls back to the built-in default, and the result
is sanitized (illegal characters stripped, whitespace collapsed).

| Key                    | Default                                                          |
| ---------------------- | ---------------------------------------------------------------- |
| `movie_folder_format`  | `{title} ({year}) {provider_tag}`                                         |
| `show_folder_format`   | `{title} ({year}) {provider_tag}`                                         |
| `season_folder_format` | `Season {season_number}`                                         |
| `movie_file_format`    | `{title} ({year}){suffix}`                                       |
| `episode_file_format`  | `{show_title} S{season_number:02d}E{episode_number:02d}{suffix}` |

**Placeholders**

- Folders: `{title}`, `{year}`, `{provider_tag}`, `{imdb_id}`,
  `{provider}`, `{provider_id}`
- Seasons: also `{season_number}`, `{season_number_00}`
- Episode files: `{show_title}`, `{season_number}`, `{season_number_00}`,
  `{episode_number}`, `{episode_number_00}`, `{quality}`, `{variant}`,
  `{suffix}`
- Movie files: `{movie_title}`, `{title}`, `{year}`, `{quality}`,
  `{variant}`, `{suffix}`

`{provider_tag}` is `[imdb-tt…]` when an IMDb id is known, otherwise
`[{provider}id-{id}]`. `{suffix}` is a pre-rendered `" - <quality/variant>"`
string (or empty), so you usually only need `{suffix}` rather than the raw
`{quality}`/`{variant}`.

The pre-rendered `{suffix}` only includes the **codec** (e.g. `[x265]`), not
the HDR flag or source. The full discriminator (codec, HDR, source) is still
stored and remains available through the `{variant}`, `{hdr}`, and `{source}`
tokens — add those to your template if you want HDR/source back in filenames,
e.g. `… {quality} [{codec}-{hdr}-{source}]`. Files imported before this change
keep their original `[x265-hdr-web]` names on disk and are still found.

<Callout type="info">

Existing folders in the old provider-id format are still detected on disk —
they are **not** renamed when you change a template.

</Callout>

## Example

```toml title="config.toml"
[misc]
frontend_url = "https://media.example.com"
cors_urls = ["https://media.example.com"]
show_directory = "/data/shows"
movie_directory = "/data/movies"
torrent_directory = "/data/torrents"
incomplete_torrent_path = "/data/torrents/incomplete"
cleanup_after_import = true
continuous_download = true
auto_download_interval_hours = 1

[misc.naming]
movie_folder_format = "{title} ({year}) {provider_tag}"
episode_file_format = "{show_title} S{season_number:02d}E{episode_number:02d}{suffix}"
```

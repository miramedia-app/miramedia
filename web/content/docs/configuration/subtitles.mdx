MiraMedia can fetch subtitles automatically. Subtitles are **enabled if
either the native search or Bazarr is enabled** — there is no separate master
toggle.

## Shared settings (`[subtitles]`)

- `desired_languages` — ISO 639-1 codes to fetch. Default `["en"]`.

## Native search (`[subtitles.native]`)

Works out of the box. Searches several providers in the languages you want.

- `enabled` — default `true`.
- `scan_interval_hours` — how often missing subtitles are scanned for. Default
  `6`. The scan job only runs when subtitles are enabled and native search is
  enabled.

### Providers

Each provider is its own table, e.g. `[subtitles.native.gestdown]`, with
`enabled` plus optional `username` / `password` / `api_key`.

**Credential-free, enabled by default:** `gestdown`, `tvsubtitles`,
`yifysubtitles`, `subtitlecat`, `subf2m`, `isubtitles`, `my_subs`,
`embeddedsubtitles`.

These need no account. `subf2m` is the Subscene successor, and the keyless
scrapers (`subtitlecat`, `subf2m`, `isubtitles`, `my_subs`) cover broad,
multi-language web sources. `embeddedsubtitles` is special: it extracts
subtitle tracks already embedded in the local video file via ffmpeg, so it
works fully offline.

**Account required, off by default** (set credentials and `enabled = true`):
`opensubtitlescom`, `addic7ed`, `subdl`, `subsource`.

**Language-specific, off by default:** `napiprojekt`, `subtis`,
`subtitulamos`.

<Callout type="info">

`subsource` requires an account and is **off by default**, even though older
example configs showed it enabled.

</Callout>

<Callout type="warn">

The legacy `opensubtitles` (XML-RPC, anonymous login no longer works) and
`bsplayer` (dead servers) providers have been **removed**. If your
`config.toml` still has `[subtitles.native.opensubtitles]` or
`[subtitles.native.bsplayer]` sections, they are automatically stripped on
load — but you should delete them. Use `opensubtitlescom` instead.

</Callout>

## Bazarr (`[subtitles.bazarr]`)

Optional external integration — an alternative to native search. MiraMedia
**impersonates Sonarr and Radarr read-only** via a compatibility shim
(`/sonarr` and `/radarr` on your MiraMedia origin). Bazarr syncs your library
through that shim, downloads subtitle files to disk, and MiraMedia's subtitle
status reads the filesystem so downloads appear automatically after the next
status scan.

When MiraMedia imports a video file, it pushes Bazarr's inbound Sonarr/Radarr
**Download** webhook so Bazarr searches immediately instead of waiting for its
next periodic sync.

### Settings

- `enabled` — default `false`.
- `url` — Bazarr's own base URL (outbound from MiraMedia to Bazarr).
- `api_key` — Bazarr's API key (outbound).
- `shim_api_key` — API key Bazarr uses when calling MiraMedia's shim. Set this
  in MiraMedia, then paste the same value into Bazarr's Sonarr/Radarr
  connection settings.

### Setup in Bazarr

1. Enable `[subtitles.bazarr]` in MiraMedia and set `shim_api_key` (generate a
   random hex string).
2. In Bazarr, add a **Sonarr** instance with URL
   `<your-miramedia-origin>/sonarr` and API key = `shim_api_key`.
3. Add a **Radarr** instance with URL `<your-miramedia-origin>/radarr` and the
   same shim key.
4. Set `url` and `api_key` in MiraMedia to Bazarr's address and API key so
   import webhooks can reach Bazarr.
5. Configure subtitle providers and language profiles in Bazarr as usual.

Use the **Test** button in MiraMedia Settings → Subtitles to verify outbound
connectivity to Bazarr.

### Mount parity

Bazarr must see your media files at the **same paths** MiraMedia reports
through the shim (or configure equivalent path mappings in Bazarr). If paths
differ, Bazarr cannot write subtitle files next to the video and MiraMedia
will not detect them.

### SignalR log noise

Bazarr logs periodic SignalR reconnect attempts against Sonarr/Radarr. The
shim does not implement SignalR — this is harmless. Library sync is driven by
Bazarr's periodic tasks plus the instant **Download** webhooks MiraMedia sends
on import.

## Example

```toml title="config.toml"
[subtitles]
desired_languages = ["en"]

[subtitles.native]
enabled = true
scan_interval_hours = 6

# Keyless providers (enabled by default — no account needed)
[subtitles.native.gestdown]
enabled = true

[subtitles.native.subf2m]
enabled = true

# Extracts subtitle tracks embedded in the video file (offline)
[subtitles.native.embeddedsubtitles]
enabled = true

# Account-required provider (off by default)
[subtitles.native.opensubtitlescom]
enabled = false
username = ""
password = ""
api_key = ""

[subtitles.bazarr]
enabled = false
url = "http://localhost:6767"
api_key = ""
shim_api_key = ""
```

Subtitle language badges appear on movie and season detail pages. Subtitles
are also streamable in the browser player, with SRT converted to WebVTT on
the fly — see [Streaming](../features/streaming).

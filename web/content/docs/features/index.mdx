These pages explain the _behavior_: how a show goes from "added" to "on disk",
how candidates are chosen, how broken imports recover, and how the supporting
features fit together. For the exact knobs, each page links to the relevant
[Configuration](/docs/configuration) reference.

- **[TV & Movies](tv-and-movies)** — tracking, continuous download, libraries.
- **[Search & Scoring](search-and-scoring)** — indexers → candidates → the
  winner.
- **[Downloads & Imports](downloads-and-imports)** — the download client, the
  import pipeline, and Imports.
- **[Streaming](streaming)** — in-browser playback and subtitles.
- **[Requests](requests)** — user requests and automatic fulfillment.
- **[Users & Auth](users-and-auth)** — sessions, superusers, OIDC.

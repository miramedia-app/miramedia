---
title: Streaming
description: "Play movies and episodes in the browser, with subtitles."
---

import { Callout } from "fumadocs-ui/components/callout";

Any imported movie or episode can be played directly in the browser from its
detail page. Playback tries the **original file** over HTTP range requests
first so seeking works immediately — no server-side transcode pipeline is
required for that path.

If the browser cannot decode the container or codecs natively, the player falls
back to in-browser remuxing or re-encoding via **WebCodecs** and
[Mediabunny](https://mediabunny.dev) when the browser exposes
`VideoDecoder` and `AudioDecoder`. When WebCodecs is unavailable or playback
still fails, use **Download** to fetch the raw file and play it locally.

<Callout type="info">

**Server-side transcoding (optional).** For containers other than MP4, M4V,
WebM, and MOV, the API may transcode once to a cached HLS bundle when `ffmpeg`
is present. That warm-cache path is separate from the browser-side fallback
above — see [Performance](../advanced-features/performance#streaming) for
details.

</Callout>

- **Seeking** works via HTTP range requests against the original file (and
  during browser-side remux/re-encode).
- **Subtitles** are served alongside the video. `.srt` is converted to WebVTT
  on the fly (the format browsers need); other formats are served as-is.
  Available languages depend on what's been fetched — see
  [Subtitles](/docs/configuration/subtitles).
- A **Download** option serves the raw file.

<Callout type="info">

Streaming requires an authenticated user. File paths are validated against
the configured library roots, so only media inside your libraries can be
streamed.

</Callout>

Playback depends on your browser, container, and codecs — MiraMedia does not
guarantee every file will play in-browser. For files that still won't play,
download and use a desktop player.

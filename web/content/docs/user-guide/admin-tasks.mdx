The **System** group in the sidebar is superuser-only. Non-admins see
"Admin access required."

## System → Settings

The settings page has a **left vertical tab sidebar** with eleven sections:
**General, Updates, Metadata, Torrents, Indexers, Scores, Subtitles, Imports,
Requests, Notifications, Authentication**. A search box filters fields across
all tabs.

### Editing flow

- Each overridden field gets an **`overridden`** badge (hover for the default
  value) and a small reset icon that resets just that field.
- Dirty tabs are marked with a coloured dot next to the tab label.
- Toolbar: **Save Settings (N)** (N = count of dirty sections), an "N unsaved
  section(s)" badge, **Reset All**, **Export**, **Import**.
- **Import** asks via a confirm dialog: **OK** = replace all overrides with
  the file, **Cancel** = merge. Toast confirms `Settings imported (replace)`
  or `(merge)`.
- Footer line: **"Changes apply immediately, no restart required."** Overrides
  are the live source of truth; `config.toml` provides the file defaults.
- Saves are **compare-and-swap** against a stored settings revision. If
  another admin (or another tab) saved while you were editing, your save is
  rejected with a revision-conflict error rather than silently overwriting
  theirs — reload and re-apply. A failed apply rolls the stored overrides back
  to the previous revision, so the file and the running config never diverge.

### Tab contents (what's worth knowing per tab)

- **General** — 5 cards: General Settings (Frontend URL, CORS, Log Retention,
  Dev Mode), **Cloudflare Bypass** (master toggle, **solver backend** picker —
  native / remote / byparr / flaresolverr / browser\_run / firecrawl — with the
  selected backend's own fields, optional proxy, and the native-only Browser
  Path / Cookie TTL / Impersonation Profile / timeouts), **Storage Paths**
  (image / torrent / movie / show dirs),
  **Libraries** (named Show/Movie roots, reorderable), **Naming** (folder /
  file format templates with full placeholder reference).
- **Updates** — Status card (current vs latest version, last-checked, repo,
  release-notes link, **Check now**, and host-side apply guidance:
  `docker compose pull && docker compose up -d`), plus an Update-settings card
  (enabled, GitHub repo, check interval, cache TTL, include pre-releases,
  notify on new version).
- **Metadata** — Desired Languages combobox, Check Interval, **Native** card
  with TVmaze + Cinemeta toggles, TMDB (Default Language + Primary
  Languages), TVDB. Each external provider has a **Test** button.
- **Torrents** — Completed Downloads / Incomplete Downloads path inputs (with
  base-prefix chips), **Cleanup after import**, **Continuous download**,
  **Auto-download interval (hours)**, plus Native Torrents and
  qBittorrent / Transmission / SABnzbd integration cards (each with **Test**).
- **Indexers** — Native indexer + Prowlarr + Jackett config (each with
  **Test**); site CRUD lives on its own page (see below).
- **Scores** — Minimum/Maximum Seeders, **Preferred / Rejected Languages**,
  Min / Max Size (MB), Recency Bonus + Decay days; reorderable **Quality
  Rules** and **Codec Rules** (per-option enable toggle, ≥1 must stay on);
  **Title Rules**, **Flag Rules**; **Score Rulesets** scoped via custom
  library names or sentinels `ALL_TV` / `ALL_MOVIES`. A live
  **`<ScoringPreview>`** at the bottom runs a synthetic title through every
  rule and shows the breakdown.
- **Subtitles** — four provider categories: **Free / keyless** (Embedded
  Subtitles, Gestdown, TVSubtitles, YIFY Subtitles, SubtitleCat, Subf2m,
  iSubtitles, My-Subs), **Account-Based** (OpenSubtitles.com [Recommended],
  Addic7ed), **API-Key** (SubDL, Subsource), **Language-Specific**
  (NapiProjekt, Subtis, Subtitulamos), plus a Bazarr Integration card
  (outbound test + a **Generate** button for the shim API key Bazarr uses on
  the Sonarr/Radarr URLs). The dead `opensubtitles` (XML-RPC) and `bsplayer`
  providers are gone and are stripped from old configs on load.
- **Imports** — Automatic Library Scan (enable + interval hours), Automatic
  Import on Scan (enable + minimum confidence 0–1 slider), Provider Matching
  (toggle + max results + auto-pick confidence threshold).
- **Requests** — Auto-approve user requests, Fulfill Interval, **Native
  Requests** toggle, **Seerr Integration** (URL + API key + Test).
- **Notifications** — **Subject Prefix**, **Native Notifications** (in-app
  bell + read-retention days), Email, Gotify, ntfy, Pushover. Each external
  provider has a **Test** button.
- **Authentication** — Session Lifetime (seconds), Email Password Resets,
  **OpenID Connect** card (enabled, Provider Name, Client ID, Client Secret,
  Configuration Endpoint, Test).

<Callout type="info">

`config.toml` still works for file-based defaults and env-var overrides — the
Settings page just makes everything editable from the UI. See
[Configuration](/docs/configuration) for the underlying schema.

</Callout>

## System → Users

Default landing for the **System** group. Columns: **Email** (with a "You"
badge on your own row), **Role**, **Last login**, **Verified**, **Status**
(Active / Inactive). Facets: Role (Admin / Regular), Status, Verified.
Group-by: Role / Status / Verified.

- **Invite User** — email + "Grant admin privileges" switch. Creates a
  verified user with a random password and emails them a reset link.
- **Add User** — email, password, **Active** / **Verified** / **Admin**
  switches; submit button **Create User**.
- Per row: **Send password reset** (key icon), **Edit** (True/False radios
  for Verified/Active/Admin, email, optional new password — "Keep empty to
  not change the password"; **Save** is a red destructive button), `⋮` →
  **Delete**.
- Bulk: **Activate** / **Deactivate**.
- Your own row has no action buttons and can't be selected — prevents
  self-lockout.

## System → Indexers

Manages indexer **sites** (preloaded **System** + **Custom** Torznab).
Columns: **Name** (Cloudflare-protected sites show a shield icon), **URL**
(link icon opens the mirror manager), **Type** (System / Custom),
**Priority** (numeric, default 100), **Supports** (Shows / Movies badges),
**Health** (Healthy / Failed pill with last-test timestamp tooltip),
**Status** (enabled / disabled).

Actions: Add / edit a site, **Test** connectivity, toggle enabled, set
priority, manage mirror URLs. Preloaded sites can be disabled or edited but
not deleted. See [Indexers](/docs/configuration/indexers) and
[Cloudflare Bypass](/docs/configuration/cloudflare).

## System → Diagnostics

**System → Diagnostics** is a superuser-only, **read-only** snapshot.
Non-admins see **"Admin access required."** Tabs: **Storage**,
**Database**, **Scheduled Tasks**.

<Callout type="warn">

This surface **diagnoses**; it does **not** repair, fix, backup, restore,
rebaseline, delete, reimport, or reacquire anything. There are no mutation
controls here. For import recovery, leave Diagnostics and use
[Imports](/docs/user-guide/importing-media). Backup and restore are not
provided on this page.

</Callout>

Failed loads show an error plus **Retry** — never a healthy or zero
snapshot. Use **System → Logs** next when you need timestamps, modules, and
log lines rather than this point-in-time view.

### Storage

Library file condition. A freshness note (default: **"Read-only library
file condition. Integrity mismatch times are last import attempt, not
audit time."**) plus **Integrity audit on/off · interval Nh**.

- Volume cards: label, path, free / used / total, **% used**. A volume
  error is shown as text, not as 0% used.
- Library badges: `name · kind`. Inaccessible roots use a destructive
  badge and **"This library root is inaccessible. Files were not marked
  missing."**
- Unconfigured library names are listed; **files were not marked missing**.
- Stat cards (click to filter the list, except **Healthy**): **Corrupt**
  (SHA1 mismatch stamps), **Orphaned** (Ghost failed rows), **Pending**
  (Acquisition recovery, plus **Open Imports**), **Unknown** (**Not yet
  hashed**, or **"Hashing disabled — imported files have no SHA1."** when
  the audit is off), **Healthy** (footer: `N imported`).
- Unknown is **not** a failure count and is never coerced to healthy or
  zero. With the audit on and unknown &gt; 0: **"Not yet hashed. The next
  audit pass will baseline or verify these files."** With the audit off:
  **"Integrity audit is off. Imported files are not hashed; this is not a
  failure count."**
- **"No imported file issues in the database. On-disk missing is not
  counted here."** when corrupt / orphaned / pending / unknown are all
  zero.
- **"Missing files are shown on title pages and in row detail when a
  directory is readable."** Missing is not a summary card.

File list columns: **Title**, **Type** (Show / Movie), **State**,
**Quality**. Search: **"Search titles…"**. Facets: **State** (Corrupt, Not
hashed, Orphaned, Pending, Healthy) and **Type** (Show, Movie). Pagination:
20 / 50 / 100 (default 50). Empty: **"No matching files"**. Row states can
also include **Missing** and **Inaccessible**.

Load errors: **"Failed to load storage"** / **"Failed to load files"** with
**"Unable to load storage diagnostics. Check that the server is reachable
and try again."** and **Retry**.

Opening a row shows a read-only sheet: **"Read-only file condition. Repair
actions live on Imports."** Diagnostics still does **not** repair from this
page. Fields: **Library**, **Quality**, **Variant**, **Import**, **Error**,
**SHA1**, **Path**. Links: **Open title**, **Open Imports** — they leave
Diagnostics.

### Database

PostgreSQL snapshot: `user@host:port/name · PostgreSQL` version, plus
**Server started** when known.

Stat cards: **Database size**, **Connections** (footer: counts by state, or
**"No activity snapshot"**), **Request pool** and **Background pool**
(`N checked out · overflow N`, or **"Engine not initialized"** / **—**
when unknown).

Table list columns: **Table**, **Total**, **Data**, **Indexes**, **Rows**
(estimated; **—** when unknown). Search: **"Search tables…"**. Empty:
**"No table sizes"** / **"Table sizes are unavailable until PostgreSQL
catalog queries succeed."** No pagination.

Load error: **"Failed to load database"** with **"Unable to load
diagnostics. Check that the server is reachable and try again."** and
**Retry**.

### Scheduled Tasks

**"Cron-scheduled background work. Interactive add-show / add-movie jobs
are not listed."** If live rows are unavailable: **"Live schedule rows were
unavailable; showing configured crons."**

Stat cards: **Background queue** and **Interactive queue** (footer:
**Waiting messages**; **—** when the depth is unknown — never coerced to
0).

Task list columns: **Task**, **Schedule**, **Cron**, **Queued** (**—** when
unknown), **Lane**. Search: **"Search tasks…"**. Empty: **"No scheduled
tasks"** / **"The scheduler catalog is empty."** No pagination.

Load error: **"Failed to load scheduled tasks"** with **"Unable to load
diagnostics. Check that the server is reachable and try again."** and
**Retry**.

## System → Logs

Paginated activity-log viewer over the database-backed `miramedia.*` log,
written by a background handler — the fastest place to diagnose issues without
shell access. Filter by **level**, **module**, **search text**, and **date
range**, and optionally **group by** level or module.

- **Follow** — toggles a 3-second auto-refresh to tail new records live.
- **Export** — downloads the current filtered view as newline-delimited JSON.
- **Clear all** — deletes every stored entry (confirm dialog).
- Captures `INFO`+ in production, or `DEBUG`+ when development mode is on. Rows
  older than `misc.log_retention_days` (default 30) are pruned daily at 03:00.

See [Logging](/docs/configuration/logging) and
[Troubleshooting](/docs/troubleshooting).

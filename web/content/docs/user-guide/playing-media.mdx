Any file showing as **imported** has a **Play** icon in the Downloads list of
its show/movie detail page.

## Playback

Click **Play** to open the video player dialog. It streams the original file
directly (seeking works immediately via range requests). If the browser's
native `<video>` element can't decode the container/codec, the player falls
back to an in-browser **WebCodecs**-based re-encode (`mediabunny`). When the
browser doesn't support WebCodecs, the error reads
**"This browser cannot play this file."** — in that case use the
**Download File** button (shown both on error and in the dialog footer) and
play it locally.

## Subtitles

Each fetched subtitle language appears as a selectable track in the player.
`.srt` is converted to WebVTT on the fly so browsers accept it. Manage which
languages are fetched in [Subtitles](/docs/configuration/subtitles), or pull
them on demand with the subtitle-search button on the detail page. Language
badges on season/movie pages show what's available.

The player footer also has a **Download** button for the raw file — useful
for files your browser can't decode, or just for offline copies.

<Callout type="info">

Playback ultimately depends on browser codec support. For exotic files,
download and play in a desktop player instead.

</Callout>

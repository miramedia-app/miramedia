The API reference is an interactive [Scalar](https://scalar.com) UI.

On a self-hosted instance, `/docs/api-reference` reads the running backend's
OpenAPI schema (`/openapi.json`), including config-gated endpoints. The hosted
GitHub Pages copy uses the committed project schema and can differ from an
installed version or configuration.
